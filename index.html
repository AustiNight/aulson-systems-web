Perspective

Hard-won beliefs. The ones that hold up.

Beliefs
→ The right tool for the wrong problem is still the wrong answer. Understand the problem first.
→ AI systems are only as good as the context they operate in. Not a detail. Not an afterthought.
→ Working software teaches things that no spec ever will. Foster a bias towards action.
→ Documentation, development, and testing are not three separate processes, they're a single loop.
→ Any data-based SDLC task can be automated with the correct LLM, harness framework, and context at the moment it begins.
→ If you can't name something clearly, you haven't understood it yet.
